1. SCOPE

   This specification covers the electric power steering system for the
   Ivo programme (DP-EPS, B segment).
   Start of production TBC.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2021-09-11   Initial issue for quotation.
   Rev B   2024-02-19   Revision following design review.



4. REQUIREMENTS

  1. [CR-ORV-13-0217] rack force capacity. The system must achieve 10182 N. (test, ASIL QM)

  2. [CR-ORV-13-0218] on center torque nm. The system should achieve 2.36 Nm. (review, ASIL B)

  3. [CR-ORV-13-0219] road wheel angle deg. The system shall achieve 51.05 deg. (analysis, ASIL QM)

  4. max current a. The system shall achieve 107 A. (inspection, ASIL QM)

  5. road wheel angle deg. The system shall achieve 54.08 deg. (analysis, ASIL B)

  6. [CR-ORV-13-0222] on center hysteresis nm. The system must achieve 0.69 Nm. (test, ASIL QM)

  7. [CR-ORV-13-0223] nvh limit db. The system shall achieve 47.52 dB. (review, ASIL B)

  8. on center hysteresis nm. The system shall achieve 0.78 Nm. (analysis, ASIL C)

  9. nvh limit db. The system shall achieve 51.45 dB. (test, ASIL QM)

  10. [CR-ORV-13-0226] on center torque nm. The system shall achieve 2.8 Nm. (inspection, ASIL QM)

  11. rack force capacity. The system should achieve 8034 N. (analysis, ASIL D)

  12. [CR-ORV-13-0228] mass kg. The system should achieve 12.35 kg. (analysis, ASIL D)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier must provide a test report referencing this
   document and the requirement identifier.
