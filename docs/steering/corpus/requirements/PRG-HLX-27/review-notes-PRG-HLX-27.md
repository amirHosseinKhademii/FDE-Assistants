# Requirements review — Haldan
**Date:** 2022-07-09 · **Chair:** S. Beker

Attendees: calibration, software, safety

## Points raised

1. Two requirements cover assist cut-off. One says taper, one says step. Taper assumed.

2. ASIL allocation for the damping path is inherited from the previous programme. Somebody should check whether that inheritance is still valid.

3. The rack force figure is stated at the rack in §4.1 and at the motor in §5.2. These are not the same number and the document does not say which governs.

4. Verification method for the on-centre requirements is "test" but no test condition is given for the 0 to 20 km/h range.

## Actions

- Check the ASIL inheritance against the current safety concept. — safety
- Raise a question to the customer on the measurement point. — systems
