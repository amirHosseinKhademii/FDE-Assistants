1. SCOPE

   This specification covers the electric power steering system for the
   Ulric programme (R-EPS, LCV segment).
   Start of production 2020-06-08.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2022-11-01   Initial issue for quotation.
   Rev B   2023-10-01   Revision following design review.
   Rev C   2021-03-01   Revision following design review.



4. REQUIREMENTS

  1. [CR-TDR-32-0537] max current a. The system shall achieve 98 A. (review, ASIL QM)

  2. [CR-TDR-32-0538] assist latency ms. The system shall achieve 7.58 ms. (review, ASIL C)

  3. on center torque nm. The system shall achieve 2.89 Nm. (analysis, ASIL B)

  4. [CR-TDR-32-0540] mass kg. The system shall achieve 10.73 kg. (inspection, ASIL C)

  5. [CR-TDR-32-0541] mass kg. The system shall achieve TBD (see §12). (analysis, ASIL QM)

  6. max current a. The system shall achieve 119 A. (test, ASIL QM)

  7. [CR-TDR-32-0543] nvh limit db. The system shall achieve 50.28 dB. (review, ASIL QM)

  8. [CR-TDR-32-0544] assist latency ms. The system shall achieve 8.27 ms. (review, ASIL C)

  9. [CR-TDR-32-0545] rack force capacity. The system shall achieve 7.2kN. (test, ASIL B)

  10. road wheel angle deg. The system shall achieve 51.26 deg. (test, ASIL QM)

  11. [CR-TDR-32-0547] road wheel angle deg. The system shall achieve 55.54 deg. (inspection, ASIL QM)

  12. [CR-TDR-32-0548] mass kg. The system shall achieve 12.63 kg. (test, ASIL B)

  13. [CR-TDR-32-0549] nvh limit db. The system shall achieve 49.9 dB. (test, ASIL C)

  14. [CR-TDR-32-0550] on center hysteresis nm. The system shall achieve 0.68 Nm. (analysis, ASIL B)

  15. nvh limit db. The system shall achieve 51.94 dB. (test, ASIL D)

  16. [CR-TDR-32-0552] nvh limit db. The system must achieve 50.19 dB. (test, ASIL B)

  17. [CR-TDR-32-0553] on center hysteresis nm. The system shall achieve 0.71 Nm. (analysis, ASIL QM)
