1. SCOPE

   This specification covers the electric power steering system for the
   Ulric programme (R-EPS, LCV segment).
   Start of production 2020-06-08.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2022-11-01   Initial issue for quotation.
   Rev B   2023-10-01   Revision following design review.
   Rev C   2021-03-01   Revision following design review.

   Changed requirements are marked with a bar in the left margin.

4. REQUIREMENTS

  1. [CR-TDR-32-0537] max current a. The system shall achieve 98 A. (inspection, ASIL C)

  2. [CR-TDR-32-0538] assist latency ms. The system shall achieve 7.58 ms. (inspection, ASIL C)

  3. [CR-TDR-32-0539] on center torque nm. The system shall achieve 2.89 Nm. (test, ASIL B)

  4. [CR-TDR-32-0540] mass kg. The system should achieve 10.73 kg. (test, ASIL C)

  5. [CR-TDR-32-0541] mass kg. The system must achieve 9.48 kg. (inspection, ASIL D)

  6. max current a. The system shall achieve 119 A. (test, ASIL B)

  7. nvh limit db. The system shall achieve 50.28 dB. (analysis, ASIL D)

  8. [CR-TDR-32-0544] assist latency ms. The system shall achieve 8.27 ms. (review, ASIL QM)

  9. rack force capacity. The system must achieve 7176 N. (test, ASIL B)

  10. road wheel angle deg. The system must achieve 51.26 deg. (analysis, ASIL D)

  11. [CR-TDR-32-0547] road wheel angle deg. The system shall achieve 55.54 deg. (inspection, ASIL C)

  12. [CR-TDR-32-0548] mass kg. The system must achieve 12.63 kg. (review, ASIL QM)

  13. [CR-TDR-32-0549] nvh limit db. The system should achieve 49.9 dB. (inspection, ASIL QM)

  14. on center hysteresis nm. The system should achieve 0.68 Nm. (analysis, ASIL B)

  15. nvh limit db. The system must achieve 51.94 dB. (analysis, ASIL B)

  16. [CR-TDR-32-0552] nvh limit db. The system should achieve 50.19 dB. (test, ASIL QM)

  17. [CR-TDR-32-0553] on center hysteresis nm. The system should achieve 0.71 Nm. (analysis, ASIL QM)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier shall provide a test report referencing this
   document and the requirement identifier.
