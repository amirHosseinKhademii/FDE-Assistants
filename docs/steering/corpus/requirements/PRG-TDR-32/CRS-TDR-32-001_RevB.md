1. SCOPE

   This specification covers the electric power steering system for the
   Ulric programme (R-EPS, LCV segment).
   Start of production 2020-06-08.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2022-11-01   Initial issue for quotation.
   Rev B   2023-10-01   Revision following design review.
   Rev C   2021-03-01   Revision following design review.



4. REQUIREMENTS

  1. max current a. The system should achieve 98 A. (test, ASIL QM)

  2. assist latency ms. The system shall achieve 7.58 ms. (review, ASIL C)

  3. on center torque nm. The system should achieve 2.89 Nm. (test, ASIL D)

  4. [CR-TDR-32-0540] mass kg. The system shall achieve 10.73 kg. (analysis, ASIL B)

  5. [CR-TDR-32-0541] mass kg. The system must achieve 9.48 kg. (inspection, ASIL C)

  6. [CR-TDR-32-0542] max current a. The system shall achieve TBD (see §12). (analysis, ASIL D)

  7. nvh limit db. The system shall achieve TBD. (inspection, ASIL B)

  8. [CR-TDR-32-0544] assist latency ms. The system must achieve 8.27 ms. (inspection, ASIL QM)

  9. rack force capacity. The system must achieve 7176 N. (review, ASIL C)

  10. road wheel angle deg. The system shall achieve 51.26 deg. (test, ASIL B)

  11. [CR-TDR-32-0547] road wheel angle deg. The system must achieve 55.54 deg. (inspection, ASIL QM)

  12. [CR-TDR-32-0548] mass kg. The system shall achieve 12.63 kg. (review, ASIL QM)

  13. [CR-TDR-32-0549] nvh limit db. The system shall achieve 49.9 dB. (inspection, ASIL C)

  14. [CR-TDR-32-0550] on center hysteresis nm. The system shall achieve 0.68 Nm. (inspection, ASIL B)

  15. [CR-TDR-32-0551] nvh limit db. The system shall achieve 51.94 dB. (test, ASIL QM)

  16. [CR-TDR-32-0552] nvh limit db. The system should achieve 50.19 dB. (test, ASIL QM)

  17. on center hysteresis nm. The system shall achieve 0.71 Nm. (inspection, ASIL QM)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier should provide a test report referencing this
   document and the requirement identifier.
