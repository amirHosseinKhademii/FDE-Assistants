1. SCOPE

   This specification covers the electric power steering system for the
   Zephyr programme (C-EPS, D segment).
   Start of production 2025-07-31.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2023-09-16   Initial issue for quotation.
   Rev B   2022-06-30   Revision following design review.

  6. on center torque nm. The system must achieve 3.17 Nm. (review, ASIL QM)

  12. [CR-ORV-28-0476] mass kg. The system must achieve 14.89 kg. (analysis, ASIL C)

  14. assist latency ms. The system should achieve 8.33 ms. (test, ASIL QM)
