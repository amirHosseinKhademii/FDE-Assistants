1. SCOPE

   This specification covers the electric power steering system for the
   Kite programme (R-EPS, D segment).
   Start of production 2022-09-29.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2022-03-05   Initial issue for quotation.

   Changed requirements are marked with a bar in the left margin.

4. REQUIREMENTS

  1. [CR-KAI-26-0441] on center hysteresis nm. The system must achieve 0.47 Nm. (review, ASIL QM)

  2. [CR-KAI-26-0442] max current a. The system must achieve 90 A. (inspection, ASIL B)

  3. [CR-KAI-26-0443] on center hysteresis nm. The system shall achieve 0.39 Nm. (analysis, ASIL B)

  4. [CR-KAI-26-0444] assist latency ms. The system shall achieve 7.01 ms. (inspection, ASIL D)

  5. nvh limit db. The system shall achieve 49.58 dB. (test, ASIL QM)

  6. [CR-KAI-26-0446] on center hysteresis nm. The system shall achieve 0.37 Nm. (inspection, ASIL C)

  7. rack force capacity. The system must achieve 10.4kN. (inspection, ASIL QM)

  8. [CR-KAI-26-0448] assist latency ms. The system shall achieve TBD (owner: chassis). (analysis, ASIL QM)

  9. [CR-KAI-26-0449] assist latency ms. The system shall achieve TBD (owner: TBC). (analysis, ASIL B)

  10. [CR-KAI-26-0450] mass kg. The system shall achieve 14.71 kg. (inspection, ASIL QM)

  11. [CR-KAI-26-0451] on center torque nm. The system shall achieve 2.29 Nm. (test, ASIL C)

  12. [CR-KAI-26-0452] nvh limit db. The system shall achieve 54.48 dB. (test, ASIL B)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier shall provide a test report referencing this
   document and the requirement identifier.
