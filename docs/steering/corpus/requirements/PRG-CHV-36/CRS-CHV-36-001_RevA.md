1. SCOPE

   This specification covers the electric power steering system for the
   Borea programme (DP-EPS, D segment).
   Start of production 2020-12-11.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2025-03-30   Initial issue for quotation.
   Rev B   2022-12-29   Revision following design review.
   Rev C   2023-11-04   Revision following design review.

   Changed requirements are marked with a bar in the left margin.

4. REQUIREMENTS

  1. [CR-CHV-36-0606] max current a. The system shall achieve 87 A. (review, ASIL B)

  2. mass kg. The system should achieve 10.73 kg. (review, ASIL QM)

  3. rack force capacity. The system should achieve 7401 N. (review, ASIL QM)

  4. mass kg. The system should achieve 11.89 kg. (inspection, ASIL C)

  5. on center hysteresis nm. The system must achieve 0.77 Nm. (analysis, ASIL B)

  6. [CR-CHV-36-0611] rack force capacity. The system shall achieve 7.3 kN. (test, ASIL C)

  7. assist latency ms. The system shall achieve 8.74 ms. (review, ASIL B)

  8. [CR-CHV-36-0613] max current a. The system shall achieve 73 A. (inspection, ASIL C)

  9. [CR-CHV-36-0614] rack force capacity. The system shall achieve 9.2kN. (inspection, ASIL C)

  10. [CR-CHV-36-0615] mass kg. The system shall achieve 14.26 kg. (analysis, ASIL D)

  11. [CR-CHV-36-0616] assist latency ms. The system must achieve 9.98 ms. (inspection, ASIL C)

  12. [CR-CHV-36-0617] on center torque nm. The system shall achieve 3.38 Nm. (inspection, ASIL QM)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier must provide a test report referencing this
   document and the requirement identifier.
