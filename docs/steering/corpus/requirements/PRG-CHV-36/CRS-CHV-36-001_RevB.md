1. SCOPE

   This specification covers the electric power steering system for the
   Borea programme (DP-EPS, D segment).
   Start of production 2020-12-11.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   Rev C   2023-11-04   Revision following design review.

4. REQUIREMENTS

  1. max current a. The system shall achieve 87 A. (test, ASIL B)

  2. mass kg. The system shall achieve 10.73 kg. (test, ASIL QM)

  3. [CR-CHV-36-0608] rack force capacity. The system should achieve 7.4kN. (inspection, ASIL QM)

  4. [CR-CHV-36-0609] mass kg. The system shall achieve 11.89 kg. (inspection, ASIL QM)

  5. [CR-CHV-36-0610] on center hysteresis nm. The system should achieve 0.77 Nm. (test, ASIL C)

  6. [CR-CHV-36-0611] rack force capacity. The system shall achieve 7.3 kN. (review, ASIL QM)

  7. assist latency ms. The system must achieve 8.74 ms. (analysis, ASIL QM)

  8. [CR-CHV-36-0613] max current a. The system shall achieve 73 A. (test, ASIL QM)

  9. rack force capacity. The system shall achieve 9.2kN. (inspection, ASIL QM)

  10. mass kg. The system must achieve 14.26 kg. (analysis, ASIL D)

  11. assist latency ms. The system shall achieve 9.98 ms. (review, ASIL B)

  12. [CR-CHV-36-0617] on center torque nm. The system should achieve TBD (owner: chassis). (analysis, ASIL QM)
