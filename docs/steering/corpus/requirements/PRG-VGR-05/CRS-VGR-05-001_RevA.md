1. SCOPE

   This specification covers the electric power steering system for the
   Oriel programme (P-EPS, SUV segment).
   Start of production 2022-06-14.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2021-04-25   Initial issue for quotation.
   Rev B   2020-05-31   Revision following design review.

   Changed requirements are marked with a bar in the left margin.

4. REQUIREMENTS

  1. [CR-VGR-05-0089] on center hysteresis nm. The system must achieve 0.39 Nm. (test, ASIL QM)

  2. [CR-VGR-05-0090] max current a. The system should achieve 76 A. (review, ASIL B)

  3. on center hysteresis nm. The system should achieve 0.38 Nm. (analysis, ASIL D)

  4. [CR-VGR-05-0092] assist latency ms. The system shall achieve 7.57 ms. (review, ASIL D)

  5. [CR-VGR-05-0093] mass kg. The system must achieve 14.62 kg. (review, ASIL B)

  6. mass kg. The system should achieve 10.55 kg. (analysis, ASIL D)

  7. [CR-VGR-05-0095] max current a. The system shall achieve 92 A. (test, ASIL D)

  8. mass kg. The system shall achieve 10.17 kg. (analysis, ASIL QM)

  9. [CR-VGR-05-0097] mass kg. The system shall achieve 11.25 kg. (test, ASIL D)

  10. [CR-VGR-05-0098] on center hysteresis nm. The system shall achieve 0.86 Nm. (analysis, ASIL C)

  11. [CR-VGR-05-0099] rack force capacity. The system shall achieve 7.9 kN. (inspection, ASIL B)

  12. [CR-VGR-05-0100] on center hysteresis nm. The system should achieve 0.57 Nm. (analysis, ASIL D)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier shall provide a test report referencing this
   document and the requirement identifier.
