1. SCOPE

   This specification covers the electric power steering system for the
   Wren programme (C-EPS, C segment).
   Start of production 2023-11-24.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2020-07-25   Initial issue for quotation.
   Rev B   2020-02-04   Revision following design review.
   Rev C   2020-08-23   Revision following design review.

   Changed requirements are marked with a bar in the left margin.

4. REQUIREMENTS

  1. on center torque nm. The system must achieve 3.27 Nm. (analysis, ASIL QM)

  2. [CR-KAI-16-0264] nvh limit db. The system shall achieve 48.91 dB. (inspection, ASIL B)

  3. [CR-KAI-16-0265] assist latency ms. The system shall achieve 7.18 ms. (inspection, ASIL QM)

  4. [CR-KAI-16-0266] assist latency ms. The system should achieve 9.29 ms. (review, ASIL B)

  5. [CR-KAI-16-0267] on center torque nm. The system shall achieve 2.85 Nm. (test, ASIL B)

  6. [CR-KAI-16-0268] on center hysteresis nm. The system shall achieve 0.73 Nm. (inspection, ASIL QM)

  7. on center hysteresis nm. The system must achieve 0.72 Nm. (test, ASIL QM)

  8. [CR-KAI-16-0270] rack force capacity. The system should achieve 8.7 kN. (analysis, ASIL D)

  9. [CR-KAI-16-0271] road wheel angle deg. The system shall achieve 47.81 deg. (review, ASIL C)

  10. [CR-KAI-16-0272] assist latency ms. The system shall achieve 8.42 ms. (test, ASIL B)

  11. [CR-KAI-16-0273] nvh limit db. The system must achieve 57.7 dB. (review, ASIL QM)

  12. [CR-KAI-16-0274] nvh limit db. The system must achieve 51.43 dB. (inspection, ASIL QM)

  13. road wheel angle deg. The system shall achieve TBD (owner: chassis). (test, ASIL C)

  14. [CR-KAI-16-0276] on center torque nm. The system should achieve 3.23 Nm. (inspection, ASIL QM)
