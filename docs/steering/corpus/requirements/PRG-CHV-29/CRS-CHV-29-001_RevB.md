1. SCOPE

   This specification covers the electric power steering system for the
   Aster programme (C-EPS, D segment).
   Start of production 2022-08-30.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2021-11-06   Initial issue for quotation.
   Rev B   2025-06-25   Revision following design review.



4. REQUIREMENTS

  1. [CR-CHV-29-0484] assist latency ms. The system should achieve TBD (see §12). (review, ASIL QM)

  2. [CR-CHV-29-0485] nvh limit db. The system shall achieve 55.88 dB. (analysis, ASIL B)

  3. [CR-CHV-29-0486] nvh limit db. The system must achieve 51.23 dB. (review, ASIL B)

  4. rack force capacity. The system must achieve 7.6 kN. (analysis, ASIL QM)

  5. [CR-CHV-29-0488] rack force capacity. The system shall achieve 6.6kN. (review, ASIL D)

  6. [CR-CHV-29-0489] max current a. The system should achieve 96 A. (review, ASIL B)

  7. [CR-CHV-29-0490] on center torque nm. The system must achieve 2.77 Nm. (analysis, ASIL B)

  8. on center hysteresis nm. The system shall achieve 0.7 Nm. (test, ASIL C)

  9. [CR-CHV-29-0492] max current a. The system must achieve 111 A. (review, ASIL B)

  10. [CR-CHV-29-0493] assist latency ms. The system shall achieve 8.03 ms. (inspection, ASIL QM)

  11. mass kg. The system shall achieve 14.75 kg. (review, ASIL B)

  12. [CR-CHV-29-0495] rack force capacity. The system must achieve 10.0 kN. (review, ASIL QM)

  13. [CR-CHV-29-0496] nvh limit db. The system shall achieve 54.44 dB. (review, ASIL B)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier shall provide a test report referencing this
   document and the requirement identifier.
