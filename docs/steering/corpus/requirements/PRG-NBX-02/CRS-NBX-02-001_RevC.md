1. SCOPE

   This specification covers the electric power steering system for the
   Hale programme (DP-EPS, SUV segment).
   Start of production 2022-05-01.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2023-06-10   Initial issue for quotation.
   Rev B   2020-12-31   Revision following design review.
   Rev C   2025-11-24   Revision following design review.

   Changed requirements are marked with a bar in the left margin.

4. REQUIREMENTS

  1. max current a. The system shall achieve 115 A. (test, ASIL D)

  2. [CR-NBX-02-0040] on center torque nm. The system shall achieve 3.18 Nm. (inspection, ASIL B)

  3. [CR-NBX-02-0041] max current a. The system shall achieve TBD. (test, ASIL C)

  4. [CR-NBX-02-0042] on center hysteresis nm. The system shall achieve 0.39 Nm. (analysis, ASIL D)

  5. [CR-NBX-02-0043] rack force capacity. The system shall achieve 10.8 kN. (test, ASIL B)

  6. [CR-NBX-02-0044] mass kg. The system shall achieve 13.9 kg. (review, ASIL B)

  7. [CR-NBX-02-0045] mass kg. The system shall achieve 11.06 kg. (inspection, ASIL B)

  8. mass kg. The system should achieve 11.44 kg. (test, ASIL C)

  9. [CR-NBX-02-0047] on center hysteresis nm. The system must achieve 0.32 Nm. (test, ASIL B)

  10. [CR-NBX-02-0048] on center hysteresis nm. The system shall achieve 0.39 Nm. (test, ASIL QM)

  11. [CR-NBX-02-0049] mass kg. The system should achieve 11.19 kg. (analysis, ASIL QM)

  12. [CR-NBX-02-0050] assist latency ms. The system shall achieve 10.3 ms. (review, ASIL QM)

  13. [CR-NBX-02-0051] mass kg. The system shall achieve 11.75 kg. (test, ASIL QM)

  14. max current a. The system should achieve 72 A. (review, ASIL C)

  15. [CR-NBX-02-0053] on center hysteresis nm. The system shall achieve 0.86 Nm. (test, ASIL QM)
