1. SCOPE

   This specification covers the electric power steering system for the
   Gale programme (C-EPS, C segment).
   Start of production 2024-01-23.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2022-11-11   Initial issue for quotation.
   Rev B   2019-12-10   Revision following design review.
   Rev C   2020-09-02   Revision following design review.



4. REQUIREMENTS

  1. nvh limit db. The system should achieve 52.75 dB. (test, ASIL B)

  2. rack force capacity. The system shall achieve 6.5kN. (review, ASIL B)

  3. on center hysteresis nm. The system shall achieve 0.34 Nm. (test, ASIL B)

  4. [CR-VGR-24-0409] assist latency ms. The system shall achieve 7.79 ms. (review, ASIL B)

  5. rack force capacity. The system should achieve 11.8kN. (review, ASIL C)

  6. assist latency ms. The system shall achieve 7.76 ms. (inspection, ASIL B)

  7. [CR-VGR-24-0412] max current a. The system shall achieve 61 A. (review, ASIL C)

  8. [CR-VGR-24-0413] on center hysteresis nm. The system shall achieve 0.88 Nm. (analysis, ASIL C)

  9. [CR-VGR-24-0414] on center torque nm. The system must achieve 2.77 Nm. (test, ASIL QM)

  10. [CR-VGR-24-0415] mass kg. The system must achieve 14.25 kg. (review, ASIL D)

  11. [CR-VGR-24-0416] nvh limit db. The system must achieve 46.14 dB. (review, ASIL C)

  12. [CR-VGR-24-0417] max current a. The system shall achieve 94 A. (inspection, ASIL D)

  13. rack force capacity. The system must achieve 9.1kN. (analysis, ASIL C)

  14. [CR-VGR-24-0419] on center torque nm. The system shall achieve 2.8 Nm. (test, ASIL C)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier must provide a test report referencing this
   document and the requirement identifier.
