1. SCOPE

   This specification covers the electric power steering system for the
   Kestra programme (C-EPS, SUV segment).
   Start of production 2025-11-19.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2022-04-10   Initial issue for quotation.
   Rev B   2020-10-19   Revision following design review.
   Rev C   2025-06-13   Revision following design review.

   Changed requirements are marked with a bar in the left margin.

4. REQUIREMENTS

  1. [CR-TDR-19-0317] on center hysteresis nm. The system should achieve 0.53 Nm. (review, ASIL QM)

  2. [CR-TDR-19-0318] assist latency ms. The system shall achieve 7.38 ms. (test, ASIL QM)

  3. [CR-TDR-19-0319] rack force capacity. The system should achieve 6.7 kN. (analysis, ASIL D)

  4. max current a. The system must achieve 116 A. (review, ASIL B)

  5. [CR-TDR-19-0321] on center torque nm. The system shall achieve 3.21 Nm. (analysis, ASIL QM)

  6. assist latency ms. The system shall achieve 8.63 ms. (test, ASIL C)

  7. nvh limit db. The system shall achieve 55.36 dB. (review, ASIL D)

  8. mass kg. The system should achieve 10.14 kg. (inspection, ASIL D)

  9. [CR-TDR-19-0325] mass kg. The system must achieve 14.9 kg. (analysis, ASIL D)

  10. road wheel angle deg. The system shall achieve 48.41 deg. (review, ASIL QM)

  11. on center torque nm. The system must achieve 2.68 Nm. (analysis, ASIL C)

  12. [CR-TDR-19-0328] nvh limit db. The system shall achieve 46.11 dB. (inspection, ASIL C)

  13. nvh limit db. The system shall achieve 48.4 dB. (analysis, ASIL C)

  14. [CR-TDR-19-0330] rack force capacity. The system must achieve 10.7kN. (inspection, ASIL D)

  15. [CR-TDR-19-0331] mass kg. The system must achieve 13.47 kg. (inspection, ASIL D)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier should provide a test report referencing this
   document and the requirement identifier.
