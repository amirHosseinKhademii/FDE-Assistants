1. SCOPE

   This specification covers the electric power steering system for the
   Iskra programme (DP-EPS, C segment).
   Start of production 2027-01-22.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2020-02-29   Initial issue for quotation.



4. REQUIREMENTS

  1. [CR-HLX-14-0229] on center torque nm. The system should achieve 2.45 Nm. (inspection, ASIL C)

  2. [CR-HLX-14-0230] max current a. The system shall achieve 89 A. (test, ASIL B)

  3. road wheel angle deg. The system shall achieve 49.21 deg. (analysis, ASIL D)

  4. assist latency ms. The system should achieve 9.42 ms. (review, ASIL C)

  5. [CR-HLX-14-0233] mass kg. The system must achieve 11.36 kg. (test, ASIL B)

  6. [CR-HLX-14-0234] on center hysteresis nm. The system shall achieve 0.56 Nm. (analysis, ASIL QM)

  7. [CR-HLX-14-0235] mass kg. The system shall achieve 9.54 kg. (inspection, ASIL B)

  8. [CR-HLX-14-0236] rack force capacity. The system shall achieve 9250 N. (inspection, ASIL QM)

  9. [CR-HLX-14-0237] on center torque nm. The system shall achieve 3.24 Nm. (inspection, ASIL QM)

  10. [CR-HLX-14-0238] assist latency ms. The system shall achieve 8.87 ms. (analysis, ASIL B)

  11. [CR-HLX-14-0239] assist latency ms. The system shall achieve 8.2 ms. (analysis, ASIL QM)

  12. [CR-HLX-14-0240] assist latency ms. The system shall achieve 10.36 ms. (review, ASIL QM)

  13. on center torque nm. The system shall achieve 3.35 Nm. (review, ASIL QM)

  14. [CR-HLX-14-0242] road wheel angle deg. The system shall achieve 51.61 deg. (review, ASIL C)

  15. [CR-HLX-14-0243] road wheel angle deg. The system should achieve 48.01 deg. (review, ASIL D)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier shall provide a test report referencing this
   document and the requirement identifier.
