# Requirements review — Iskra
**Date:** 2022-01-17 · **Chair:** M. Lindqvist

Attendees: safety, calibration, software, PM

## Points raised

1. Verification method for the on-centre requirements is "test" but no test condition is given for the 0 to 20 km/h range.

2. The rack force figure is stated at the rack in §4.1 and at the motor in §5.2. These are not the same number and the document does not say which governs.

3. ASIL allocation for the damping path is inherited from the previous programme. Somebody should check whether that inheritance is still valid.

4. Two requirements cover assist cut-off. One says taper, one says step. Taper assumed.

5. Mass target looks aggressive against the force class. Flagged to purchasing, not resolved here.
