1. SCOPE

   This specification covers the electric power steering system for the
   Tarn programme (P-EPS, B segment).
   Start of production 2025-06-01.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2020-07-02   Initial issue for quotation.
   Rev B   2024-10-09   Revision following design review.
   Rev C   2024-11-08   Revision following design review.



4. REQUIREMENTS

  1. [CR-MRL-04-0075] nvh limit db. The system must achieve 48.33 dB. (analysis, ASIL D)

  2. on center torque nm. The system shall achieve 3.33 Nm. (inspection, ASIL C)

  3. [CR-MRL-04-0077] mass kg. The system must achieve 12.88 kg. (test, ASIL QM)

  4. [CR-MRL-04-0078] mass kg. The system should achieve 12.32 kg. (inspection, ASIL QM)

  5. [CR-MRL-04-0079] road wheel angle deg. The system must achieve 55.56 deg. (review, ASIL C)

  6. [CR-MRL-04-0080] mass kg. The system shall achieve 12.96 kg. (inspection, ASIL D)

  7. [CR-MRL-04-0081] rack force capacity. The system shall achieve 9.8kN. (inspection, ASIL D)

  8. [CR-MRL-04-0082] max current a. The system should achieve 103 A. (review, ASIL QM)

  9. [CR-MRL-04-0083] mass kg. The system should achieve 10.98 kg. (test, ASIL QM)

  10. [CR-MRL-04-0084] mass kg. The system should achieve 9.71 kg. (inspection, ASIL QM)

  11. on center torque nm. The system should achieve 3.12 Nm. (test, ASIL D)

  12. [CR-MRL-04-0086] assist latency ms. The system should achieve 10.88 ms. (analysis, ASIL QM)

  13. assist latency ms. The system must achieve 8.87 ms. (test, ASIL B)

  14. nvh limit db. The system shall achieve 55.19 dB. (test, ASIL B)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier shall provide a test report referencing this
   document and the requirement identifier.
