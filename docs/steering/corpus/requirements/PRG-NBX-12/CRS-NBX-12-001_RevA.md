1. SCOPE

   This specification covers the electric power steering system for the
   Yarrow programme (R-EPS, C segment).
   Start of production 2028-06-24.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   

3. CHANGE RECORD

   Rev A   2022-03-18   Initial issue for quotation.
   Rev B   2022-07-21   Revision following design review.



4. REQUIREMENTS

  1. [CR-NBX-12-0201] rack force capacity. The system shall achieve 11.1kN. (analysis, ASIL B)

  2. assist latency ms. The system shall achieve 8.02 ms. (inspection, ASIL D)

  3. road wheel angle deg. The system should achieve 52.96 deg. (review, ASIL B)

  4. [CR-NBX-12-0204] on center hysteresis nm. The system shall achieve 0.67 Nm. (test, ASIL QM)

  5. [CR-NBX-12-0205] max current a. The system shall achieve 68 A. (test, ASIL QM)

  6. [CR-NBX-12-0206] max current a. The system shall achieve 107 A. (test, ASIL QM)

  7. mass kg. The system should achieve 11.02 kg. (analysis, ASIL C)

  8. [CR-NBX-12-0208] nvh limit db. The system shall achieve 47.33 dB. (analysis, ASIL D)

  9. [CR-NBX-12-0209] on center hysteresis nm. The system should achieve 0.74 Nm. (review, ASIL B)

  10. [CR-NBX-12-0210] mass kg. The system should achieve 14.54 kg. (analysis, ASIL B)

  11. [CR-NBX-12-0211] on center hysteresis nm. The system shall achieve 0.58 Nm. (analysis, ASIL QM)

  12. [CR-NBX-12-0212] nvh limit db. The system shall achieve 54.07 dB. (test, ASIL D)

  13. [CR-NBX-12-0213] rack force capacity. The system shall achieve 7.4kN. (review, ASIL B)

  14. road wheel angle deg. The system shall achieve 45.78 deg. (test, ASIL C)

  15. [CR-NBX-12-0215] assist latency ms. The system shall achieve 6.94 ms. (inspection, ASIL QM)

  16. [CR-NBX-12-0216] max current a. The system should achieve 74 A. (review, ASIL D)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier shall provide a test report referencing this
   document and the requirement identifier.
