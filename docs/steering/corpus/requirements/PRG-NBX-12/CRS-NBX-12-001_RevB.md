1. SCOPE

   This specification covers the electric power steering system for the
   Yarrow programme (R-EPS, C segment).
   Start of production 2028-06-24.

2. DEFINITIONS

   shall   mandatory. Non-compliance requires a written concession.
   should  recommended. Deviation requires justification at the design review.
   must    mandatory.

   (Note: earlier sections of this document use "must" and "shall"
   interchangeably. Both are mandatory.)

3. CHANGE RECORD

   Rev A   2022-03-18   Initial issue for quotation.
   Rev B   2022-07-21   Revision following design review.



4. REQUIREMENTS

  1. rack force capacity. The system shall achieve 11.1 kN. (test, ASIL B)

  2. assist latency ms. The system must achieve 8.02 ms. (review, ASIL QM)

  3. [CR-NBX-12-0203] road wheel angle deg. The system must achieve 52.96 deg. (analysis, ASIL QM)

  4. [CR-NBX-12-0204] on center hysteresis nm. The system shall achieve TBD (owner: TBC). (review, ASIL QM)

  5. [CR-NBX-12-0205] max current a. The system shall achieve 68 A. (inspection, ASIL QM)

  6. max current a. The system should achieve 107 A. (test, ASIL D)

  7. [CR-NBX-12-0207] mass kg. The system should achieve 11.02 kg. (inspection, ASIL QM)

  8. [CR-NBX-12-0208] nvh limit db. The system shall achieve 47.33 dB. (inspection, ASIL D)

  9. [CR-NBX-12-0209] on center hysteresis nm. The system shall achieve 0.74 Nm. (analysis, ASIL QM)

  10. [CR-NBX-12-0210] mass kg. The system shall achieve 14.54 kg. (analysis, ASIL B)

  11. on center hysteresis nm. The system shall achieve 0.58 Nm. (analysis, ASIL QM)

  12. nvh limit db. The system must achieve 54.07 dB. (analysis, ASIL D)

  13. [CR-NBX-12-0213] rack force capacity. The system shall achieve 7406 N. (test, ASIL B)

  14. [CR-NBX-12-0214] road wheel angle deg. The system must achieve 45.78 deg. (review, ASIL C)

  15. [CR-NBX-12-0215] assist latency ms. The system shall achieve 6.94 ms. (inspection, ASIL D)

  16. [CR-NBX-12-0216] max current a. The system shall achieve 74 A. (analysis, ASIL B)



5. VERIFICATION

   Verification method per requirement is given above. Where the method is
   "test", the supplier must provide a test report referencing this
